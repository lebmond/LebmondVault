# 一、证券公司治理的基本要求
1. 建立健全组织架构,明确职责划分
2. 不得侵犯客户合法权益
3. 建立完备的内部控制体系
4. 建立稳健的薪酬制度
董事会对合规管理、风险管理和内部控制体系的有效性承担**最终责任**.


# 二、证券公司与股东之间关系的特别规定
1. 不得滥用权力
2. 不得超越职权(**有表决权,但是不能直接任免**)
3. 依法维护证券公司独立性
4. 不得开展业务竞争
5. 关联交易不得损害公司利益
6. 不得虚假出资,抽逃出资
7. 不得违规要求提供融资或担保
8. 未经批准不得委托持股
不得有下列的行为:
9. 持有股东的股权,但法律,行政法规或者中国证监会另有规定的除外
10. 通过购买股东持有的证券等方式向股东输送不当利益
11. 股东违规占用公司资产

# 三、证券公司董事、监事、高级管理人员的任职条件
[[独立董事]]制度

需要同时满足:
1. 熟悉证券基金法律法规和中国证监会的规定
2. 具备**3年以上**与其拟任职务相关的证券,基金,金融,法律,会计,信息技术等工作经历
3. 具有与拟任职务相适应的管理经历和经营管理能力
拟任证券基金经营机构高级管理人员应额外满足以下其中一项条件:
4. 具有相当职位管理经历(职位完全对口)
5. 曾担任==证券基金经营==机构部门负责人以上职务**不少于2年**(机构对口)
6. 曾担任==金融机构==部门负责人以上职务**不少于4年**(都不对口)

## 聘任流程
1. 证券公司聘任董事,监事和高级管理人员前,应审慎考察并确认其:符合相应的任职条件,自作出聘任决定之日起**5个工作日内**向中国证监会相关派出机构(即证监局)报送相关备案材料
2. 中国证监会相关派出机构发现受聘人不符合任职条件的,证券公司应当立即停止受聘人职务,及时解除对受聘人的聘任决定,并自作出解聘决定之日起**5个工作日内**向中国证监会相关派出机构(即证监局)报告

# 五、对证券公司董事会的相关要求
1. 证券公司董事会**每年至少召开两次会议**,除由于紧急情况,不可抗力等特殊原因无法举行现场,视频或者电话会议外,董事会会会议应当采取**现场,视频或者电话会议**方式
2. 董事会会议应当制作会议记录,并可以**录音**,会议记录应当**真实,准确,完整**,并依法保存.出席会议的董事和记录人应当在会议记录上签字
3. 证券公司董事会决议内容违反法律,行政法规或者中国证监会的规定的,==监事会==应当要求董事会纠正,==经理层==应当拒绝执行
4. 证券公司董事会,董事长应当在法定权限范围内行使职权,不得越权干预经理层的经营管理活动
5. 证券公司设董事会的,==内部董事人数不得超过董事人数的1/2==,证券公司可以聘请外部专业人士担任董事
6. 证券公司应当设[[董事会秘书]],依法提供有关资料,办理信息报送或者信息披露事项
7. 董事会表决有关关联交易的议案时,与交易对方有关联关系的董事应当回避
8. 该次董事会会议由**过半数**的无关联关系董事出席即可举行,董事会会议所作决议须经无关联关系董事过半数致通过
9. 出席董事会的无关联关系董事人数不足**3**人的,应当将该事项提交股东(大)会审议

# 六、对董事会专门委员会的要求

> [!NOTE] Title
> 经管融承保
> 两种及以上
> 薪提审计会
> 独立风控会

证券公司经营证券经纪业务,证券资产管理业务,融资融券业务和证券承销与保荐业务中**两种及以上**业务的,其董事会应当建立[[独立董事]]制度,以及设立薪酬与提名委员会,审计委员会和风险控制委员会.
## 其他规定
1. 专门委员会可以聘请外部专业人士提供服务,由此发生的合理费用由证券公司承担
2. 专门委员会应当向董事会负责,按照公司章程的规定向董事会**提交工作报告**
3. 董事会在对与专门委员会职责有关的事项作出决议前,应当听取专门委员会的意见
4. 证券公司董事会各专门委员会应**由董事组成**,专门委员会成员应当具有与专门委员会职责相适应的**专业知识和工作经验**
5. ==审计委员会==中独立董事的人数不得少于1/2,且至少有1名独立董事从事会计工作5年以上

# 七,对监事会的要求
1. 证券公司设监事会的,监事会应当设主席,可以设副主底,监事会主席是监事会的召集人.
2. 除由于紧急情况,不可抗力等特殊原因外,监事会会议应当采取现场,视频或者电话会议方式.证券公司监事会会议应当制作会议记录,并可以录音,会议记录应当依法保存.
3. 证券公司监事有权了解公司经营情况,并承担相应的**保密义务**.监事会应当就公司的财务情况,合规情况向股东(大)会年会作出专项说明
4. 监事会可根据需要对公司财务情况、合规情况进行专项检查,必要时可聘请外部专业人士协助.
5. 证券公司监事会可要求公司董事,高级管理人员及其他相关人员出席监事会会议,回答问题.
6. 对董事,高级管理人员违反法律,行政法规或者公司章程,损害公司,股东或者客户利益的行为,证券公司监事会应当要求董事,高级管理人员限期改正.
7. 损害严重或者董事,高级管理人员未在限期内改正的,监事会应当提议召开股东(大)会,并向股东(大)会提出专项议案.
8. 对董事会,高级管理人员的重大违法违规行为,监事会应当直接向中国证监会或者其派出机构报告.
# 八、对高级管理人员的要求
(1)证券公司高级管理大员不得同时在其他证券基金经营机构执业,不得在其他营利性机构兼职,但法律,行政法规或中国证监会另有规定除外.
(2)证券公司设立管理委员会,执行委员会等机构行使总经理职权的,应当在公司章程中明确其名称,组成,职责和议事规则,其组成人员应当向住所地中国证监会派出机构备案.
