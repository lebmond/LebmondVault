由一定人数以上的股东组成,公司全部资本分为等额股份,股东以其认购的份额为限对公司承担责任,公司以其全部资产对外承担民事责任的企业法人

|       | [[有限责任公司]]        | [[股份有限公司]]   |
| ----- | ----------------- | ------------ |
| 人数要求  | 人数至少一人,至多五十人<br>  | 人数至少五十人,无上限  |
| 股份流动性 | 股份转让前需征求其他股东意见    | 自由交易         |
| 融资方式  | **不可以**公开募集资金     | 可以公开发行股份募集资金 |
| 设立方式  | [[发起设立]]和[[募集设立]] | 仅能[[募集设立]]   |
