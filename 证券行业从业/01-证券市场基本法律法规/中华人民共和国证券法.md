# 适用范围
1. 在中华人民共和国境内，==股票、公司债券、存托凭证==和国务院依法认定的其他证券的==发行和交易==
2. 政府债券、证券投资基金份额的上市交易
3. 资产支持证券(ABS)、资产管理产品（Trust Fund)==发行、交易==的管理办法，由国务院依照《证券法》的原则规定
4. 在中华人民共和国境外的证券发行和交易活动，扰乱中华人民共和国境内市场秩序，损害境内投资者合法权益的，依照《证券法》有关规定处理并追究法律责任
注意非上市的公开募集资金的证券投资基金不适用证券法而适用基金法。
# 三公原则
公开 公平 公正
# 发行交易当事人的行为准则
自愿 有偿 诚实信用

# 证券发行、交易活动禁止行为
1. 欺诈交易
2. [[内幕交易]]
3. [[操纵证券市场]]
4. 出借或者借用证券账户从事证券交易；
5. 禁止资金违规流入股市。禁止违规利用财政资金、银行信贷资金买卖证券；

# 证券发行
分为[[公开发行]]和非公开发行。
未经依法注册，任何单位和个人不得[[公开发行]]证券。证券发行注册制的具体范围、实施步骤，由国务院规定。
非公开发行证券的，不得采用广告、公开劝诱和变相公开方式。

# 上市公司的收购
## 种类
### [[要约收购]]
### 协议收购
达成协议后，收购人3日内将收购协议报告并予以公告。

要约收购和协议收购的比较

|      | 要约收购                                             | 协议收购                                                                   |
| ---- | ------------------------------------------------ | ---------------------------------------------------------------------- |
| 交易场地 | 仅限证券交易所内进行证券交易                                   | 可以场外通过协议转让股份的方式                                                        |
| 股份限制 | 收购人持有上市公司发行在外的股份达到30%时，若要继续收购，需要被收购公司的全体股东发出收购要约 |                                                                        |
| 收购态度 | 要约收购的对象则是目标公司全体股东持有的股份，不需要征得公司的同意，因此要约收购又称敌意收购。  | 协议收购是收购者与目标公司的控股股东或大股东奔着友好协商的态度，订立合同收购股份，以实现公司控制权的转移<br>所以协议收购通常表现为善意的 |
| 收购对象 | 股权较为分散的公司，以降低收购难度                                | 大多选择股权集中存在控股股东的自标公司                                                    |
收购性质不同，根据收购人收购的股份占该上市公司已发行股份的比例，上市公司收购可分为部分收购和全面收购两种。部分收购是指试图收购一家公司少于100%的股份而获得对该公司控制权的行为，它是公司收购的一种，与全面收购相对应。

## 收购的程序和规则
通过证券交易所的证券交易，投资者持有或者通过协议、其他安排与他人共同持有一家上市公司已发行的有表决权股份达到5%时，应当在该事实发生之日起3日内，向国务院证券监督管理机构、证券交易所作出书面报告，通知该上市公司，并予公告。在上述期限内不得再行买卖该上市公司的股票，但国务院证券监督管理机构规定的情形除外。
### 持股比例每增减5%
投资者持有或者通过协议、其他安排与他人共同持有一家上市公司已发行的有表决权股份达到5%后，其所持该上市公司已发行的有表决权股份比例每增加或者减少5%，应当在该事实发生之日起至公告后3日内，不得再行买卖该上市公司的股票，但国务院证券监督管理机构规定的情形除外。违反上述规定买入上市公司有表决权的股份的，在买入后的36个月内，对该超过规定比例部分的股份不得行使表决权。
### 持股比例每增减1%
投资者持有或通过协议，其他安排与他人共同持有一家上市公司已发行的有表决权股权达到5%后，其所持该上市公司已发行的有表决权股份比例每增加或者减少1%，应当在该事实发生的次日通知该上市公司，并予公告。
### 持股比例达到30%
采取==协议收购==方式的，收购人收购或者通过协议、其他安排与他人共同收购一家上市公司已发行的有表决权股份达到30%时，继续进行收购的，应当依法向该上市公司所有股东发出收购上市公司全部或者部分股份的要约。但是，按照国务院证券监管厘机构的规定兔除及出要约的除外。

在上市公司收购中，收购人持有的被收购的上市公司的股票，在收购行为完成后的==18个月内不得转让==
收购行为完成后，收购人与被收购公司合并，并将该公同解散的，被解散公司的原有股票由收购人依法更换
收购行为完成后，收购人应当在15日内将收购情况报告国务院证券监督管理机构和证券交易所，并予公告
上市公司分立或者被其他公司合并，应当向国务院证券监督管理机构报告，并予公告
