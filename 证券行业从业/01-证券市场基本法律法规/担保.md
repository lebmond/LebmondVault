# 公司提供担保的方式
1. 保证：由第三方和债权人做出保证
2. 抵押：不会影响财产占有的转移（除非还不上钱）
3. [[质押]]
4. （仅做了解）定金
5. （仅做了解）留置
# 对外担保的规定
1. 向其他企业投资或者为他人提供担保，依照公司章程的规定，由(1)董事会**或**(2)股东会或者股东大会决议；
2. [[公司章程]]对投资或担保的总额及单项投资或者担保的数额有限额规定的，不能超过规定的限额

# 对内担保的规定
1. 公司为公司股东或者实际控制人提供担保的，必须经**股东会或股东大会决议**（**但不需要董事会**）
2. 对于被担保人股东或者受被担保实际控制人支配的股东，不得参加该担保事项的表决
3. 该项表决有出息会议的其他股东所持表决权的**过半数**通过

## [[股份有限公司]]提供担保的另外规定
董事会应当及时召集股东大会会议，由股东大会就上述事项进行表决

## 上市公司提供担保的另外规定
1. 上市公司在一年内担保金额超过公司**资产总额百分之三十**的，  应当由股东大会作出决议，并经出席会议的股东所持表决权的**2/3以上**通过
2. 上市公司不得为任何**非法人单位和个人提供担保**
3. 上市公司对外担保必须要求对方（债务人）提供**反担保**，且反担保的提供方应当具有实际承担能力
