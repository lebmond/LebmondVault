# 概念
即基金投资者，是基金的出资人、基金投资管理的委托人和基金收益的受益人。
# 分类方式
## 按照资金募集方式的不同
分为公募基金份额持有人与[[非公开募集基金|私募基金]]份额持有人（[[非公开募集基金|私募基金]]的“门槛要求”高于公募基金份额持有人，[[非公开募集基金|私募基金]]投资者应为[[合格投资者]]）。

### 普通投资者
专业投资者以外的投资者即为普通投资者，包括机构投资者和个人投资者。

# 公募基金的份额持有人大会
1. 召集主体：日常机构，管理人，托管人，或10%份额以上持有人。
2. 会前公告：提前==30日==公布。
3. 召开方式：可以采取现场方式召开，也可以采取通讯等方式召开。
4. 召开条件：代表1/2以上份额出席，重召（==3月以上6月以内==）=1/3以上份额出席。
5. 表决规则：
	1. 一般事项-过半数同意；
	2. 重大事项（更换管理人/托管人、提前终止、合同修改）-2/3 同意。
6. 备案与公告：基金份额持有人大会决定的事项，应当依法报国务院证券监督管理机构备案，并予以公告。
