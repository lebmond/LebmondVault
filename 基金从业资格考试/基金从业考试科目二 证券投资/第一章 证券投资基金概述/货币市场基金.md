# 概念
以货币市场工具为投资对象，仅投资于[[货币市场工具]]的基金为货币市场基金。

# 特点
## 投资目标和风险收益特征
风险和预期收益低于股票基金、混合基金和[[债券基金]]，是厌恶风险、对资产流动性和安全性要求较高的投资者进行短期投资和现金管理的理想工具。

## 投资对象
1. 现金；
2. 期限在1年以内（含1年）的银行存款、债券回购、中央银行票据、[[同业存单]]
3. 剩余期限在397 天以内（含 397天）的债券、非金融企业债务融资工具、资产支持证券；
4. 中国证监会、中国人民银行认可的其他具有良好流动性的货币市场工具。
## 高流动性特征：
风险低、流动性好。

# 类型
## 按照估值方法分类
1. 固定净值型货币市场基金；
2. 浮动净值型货币市场基金；
## 按照交易模式分类
1. 申赎型货币市场基金；
2. 交易型货币市场基金（货币市场ETF）；
	1. 上交所交易型
	2. 深交所交易型
