# 一、投资决策委员会：
基金管理人投资管理的最高决策机构，由基金管理人自行设立。
应在遵守国家有关法律法规及公司规章制度的前提下，对基金管理人各项重大投资活动进行管理，审定公司投资管理制度和业务流程，并确定不同管理级别的操作权限。
# 二、投资部门：
基金管理人的核心业务部门，其主要职责是根据投资决策委员会制订的投资原则和计划，设计并执行具体的投资组合方案。
# 三、研究部门：
基金投资运作的基础支持部门。
# 四、交易部门：
基金投资运作的具体执行部门，负责投资组合交易指令的审核、执行与反馈。
# 五、风险管理委员会：
基金公司加强风险管理统筹协调的重要机构，在投资研究流程中发挥着关键作用。
# 六、风险管理部门：
基金管理人风险管理的主要职能门，负责日常统筹、协调和实施各项风险管理工作。
# 七、法律合规部门：
基金管理人确保合规运营的关键部门，直接向合规负责人汇报。
