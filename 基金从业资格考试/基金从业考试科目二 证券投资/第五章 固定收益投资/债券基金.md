# 概念
以债券为主要投资对象，根据中国证监会对基金类别的分类标准，基金资产80%以上投资于债券的基金为债券基金。

# 特点
收益稳定、中低分险。

# 和债券的区别

| 区别            | 债券基金                                                  | 债券                                          |
| ------------- | ----------------------------------------------------- | ------------------------------------------- |
| 收益是否固定        | 债券基金分配的收益有升有降，不如债券的利息固定                               | 购买固定利率性质的债券，定期得到固定的利息，债券到期时收回本金             |
| 确定<br>的到期日    | 由一组具有不同到期日的债券组成，因此并没有个确定的到期日                          | 一般债券会有一个确定的到期日                              |
| 收益率是否<br>难以预测 | 由一组不同的债券组成，其整体收益率的计算和预测相对更为复杂                         | 投资者可以根据购买价格、票息现金流以及到期收回的本金计算单一债券的投资收益率      |
| 投资风险不同        | ①所承受的利率风险通常会保持在一定的水平<br>②通过分散投资可以有效避免单一债券可能面临的较高的信用风险 | ①单一债券随着到期日的临近，所承担的利率风险会下降<br>②单一债券的信用风险比较集中 |
