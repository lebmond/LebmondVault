# 概念
指证券期货经营机构（管理人）管理的同时符合以下特征的资产管理产品：
- 管理人按照要求委托两个或者两个以上符合条件的第三方资产管理机构（投资顾问）就资产管理产品的部分或者全部资产提供投资建议；
- 根据资产配置需要将资产管理产品的资产划分成两个或者两个以上资产单元，每一个资产单元按规定单独开立证券期货账户。
- 其中，由基金管理人管理的公开募集的MOM产品即MOM基金。
# 特点：
- 大类资产配置；
- 精选子管理人；
- 分散风险，提升收益；
- 专业管理。
- 多元管理，多元资产，多元风格。
# MOM产品的类型：
- 股票型MOM；
- 债券型MOM；
- 混合型MOM；
- 其他类型MOM。
