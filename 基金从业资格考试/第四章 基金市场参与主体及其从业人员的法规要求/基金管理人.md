# 地位
在基金运作的整体过程中处于==核心地位==。
# 主要职责
按照基金合同的约定，负责基金产品生命周期各个环节的运作，在有效控制风险的基础上==为基金投资者获取最大的投资收益==。
## 公募基金管理人的法定职责
1. 依法**募集资金**，办理基金份额的发售和登记事宜；
2. 办理基金**备案**手续；
3. 对所管理的不同基金财产分别管理、分别记账，进行证券投资；
4. 按照基金合同的约定确定基金**收益分配**方案，及时向基金份额持有人分配收益；
5. 进行基金会计核算并编制基金财务会计报告；
6. 编制中期和年度基金报告；
7. 计算并公告基金**资产净值**，确定基金份额申购、赎回价格；
8. 办理与基金财产管理业务活动有关的**信息披露**事项；
9. 按照规定召集基金份额持有人大会
10. 保存基金财产管理业务活动的记录、账册、报表和其他相关资料；
11. 以**基金管理人名义**，代表[[基金份额持有人]]利益行使诉讼权利或实施其他法律行为；

由依法设立的公司或者合伙企业担任。
# 准入限制
公募基金的基金管理人有严格的准入限制，而[[非公开募集基金|私募基金]]管理人的准入要求相对宽松。
## 公募基金管理人的准入
### 设立公募基金管理公司具备的条件
1. 合法合规；
2. 注册资本不低于**1亿元**人民币，且股东必须以来源合法的自有货币资金**实缴**，境外股东应当以**可自由兑换货币**出资；
3. 有符合法律、行政法规和中国证监会规定的董事、监事、高级管理人员以及研究、投资、运营、销售、合规等岗位职责人员，**取得基金从业资格的人员原则上不少于30人**。
### 公募基金管理公司的股东分类
根据持股比例和对公募基金管理公司经营管理的影响，公募基金管理公司股东包括三类： 
1. 主要股东，指持有基金管理公司25%以上股权的股东，如任一股东持股均未达25%的，则主要股东为持有5%以上股权的第一大股东，中国证监会另有规定的除外；
2. 持有基金管理公司5%以上股权的非主要股东；
3. 持有基金管理公司5%以下股权的非主要股东。
### [[其他资产管理机构]]的准入
### 一参一控原则
2004年9月规定，防止一家机构控制多家公募公司，避免风险集中和潜在利益输送。
例外原则：
1. 直接持有和间接控制基金管理公司股权的比例低于5%；
2. 为实施基金管理公司并购重组所做的过渡期
3. 安排基金管理公司设立从事公募基金管理业务的子公司

# 公募基金和[[非公开募集基金|私募基金]]的管理人
- 公募基金的管理人由基金管理公司或者中国证监会按照规定核准的其他机构担任。
- [[非公开募集基金|私募基金]]管理人无需中国证监会核准，但需按照规定向[[中国证券投资基金业协会]]履行登记手续、报送基本情况。

# 治理
## 公募基金管理人的治理
三会一层
### 股东会
公司章程应当明确股东会的职权范围和议事规则。公募基金管理人应当建立与股东之间的业务和客户关键信息隔离制度。
### 董事会 
董事会和董事长不得越权干预经理层的具体经营活动
公募基金管理人的总经理应当为董事会成员；
公募基金管理人应当建立健全[[独立董事]]制度，提供必要条件保障独立董事有效、独立履行职责。  
## 监事（会）或审计委员会层面
设置监事(会）或审计委员会行使**内部监督职能**；
监事（会）的设置应当符合中国证监会的规定。监事(会)**不得越权干预**经理层的具体经营活动；
按照《公司法》和公司章程等规定在董事会中设置由董事组成的审计委员会，行使监事会职权的，不设监事（会）；
董事会成员中的**职工代表**可以成为审计委员会成员。
## 经营层层面
总经理负责

# 经营
## 公募基金管理人的经营
1. 公募基金管理人经过**中国证监会**的核准，主要从事公募基金管理业务。
2. 经中国证监会批准或者认可，公募基金管理人可以从事私募资产管理业务和其他相关业务。公募基金管理人从事各项业务应当坚持**审慎经营**原则。
3. 公募基金管理人可以设立[[公司#^4af127|子公司]]或分公司等中国证监会规定形式的分支机构，按照中国证监会的规定从事相关业务
## 公募基金管理人的国际化业务
1. 基金进行跨境投资、销售或管理等被称为基金国际化。基金的国际化是伴随着经济全球化、证券市场国际化的发展出现的，是当前基金行业发展的重要趋势之一。
2. 我国公募基金管理人开展基金国际化业务历程
	1. 申请QDII资格和额度开展境外投资；
	2. 设立境外经营机构拓展境外业务；
	3. 通过基金互认在境外市场向公众投资者销售基金；
	4. 通过互联互通机制交易香港市场的股票等多元化发展的国际业务。
### 境外经营机构管理
《证券公司和证券投资基金管理公司境外设立收购、参股经营机构管理办法》
主要包括四个方面的内容：
1. 维持适当门槛，支持机构走出去
2. 规范业务范围，完善组织架构。
3. 督促母公司加强管控，完善境外机构管理。
4. 加强持续监管，完善跨境监管合作。
### 基金互认
基金互认是指允许境外注册并受当地监管机构监管的基金向本地居民公开销售。中国证监会、香港证监会已经通过基金互认。
互联互通： 沪港通、深港通。 债券通： 北向通、南向通

## 风险准备金制度和财务指标
1. 为了增强公募基金管理人的风险防范能力，保护基金份额持有人的利益，基金管理人应当依法建立风险准备金制度。公募基金管理人应当从管理基金的==报酬中去计提==风险准备金。
2. 公募基金管理人因违法违规、违反基金合同等原因给基金财产或者基金份额持有人合法权益造成损失，应当承担赔偿责任的，可以优先使用风险准备金予以赔偿。
3. 对于财务指标，公募基金管理人总负债不得超过净资产的100%，中国证监会另有规定的，从其规定。
