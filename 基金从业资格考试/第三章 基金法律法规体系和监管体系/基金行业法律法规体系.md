# 法律法规体系层级

> [!SUMMARY] 
> 纵向四层不同的效力，横向覆盖各种基金。

从纵向来看，我国基金行业法律法规体系按效力从高到低分为四个层级：
1. 国家法律：是由全国人民代表大会及其常务委员会制定的规范，效力层级最高。
2. 行政法规：是国务院为领导和管理国家各项行政工作。
3. 部门规章和规范性文件：是国务院所属的各部、委员会根据法律和行政法规制定的规范。
4. 自律规则：是行业协会、交易场所等制定和实施的规范。
从横向来看，我国基金行业法律法规体系适用于不同类型的基金、私募资产管理计划，以及基金业务的各个方面。
# 法律法规体系的适用范围
## 覆盖不同类型的基金
1. 公募基金可以向不特定对象募集资金，事关中小投资者权益，因此其规范相对较早、法律法规数量最多
2. 私募资产管理计划产生晚于公募基金，且由于其管理人的经营管理、计划财产托管等与公募基金相同或相似，因此针对私募资产管理计划的专项法律法规数量相对较少
3. 私募基金的规范相对较晚，虽然私募基金的投资者均须为满足较高投资门槛的投资者，但考虑到私募基金数量，日趋增多。
