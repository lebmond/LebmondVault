# 应具备的条件
## 机构投资者
经有关金融监管部门批准设立的金融机构，及其面向投资者发行的理财产品；社保基金、企业年金等养老基金，慈善基金等社会公益基金，合格境外机构投资者(QFII)、人民币合格境外机构投资者(RQFII) 。
## 法人或者其他组织
同时符合下列条件的:
1. 最近1年末净资产不低于2000万元
2. 最近1年末金融资产不低于1000万元
3. 具有2年以上证券、基金、期货、黄金、外汇等投资经历
## 自然人
1. 金融资产不低于500万元，或者最近3年个人年均收入不低于50万元
2. 具有**2年**以上证券、基金、期货、外汇等投资经历，或者具有**2年**以上金融产品设计、投资、风险管理及相关工作经历，或者属于金融机构的专业投资者的高级管理人员、获得职业资格认证的从事金融相关业务的注册会计师和律师

# 专业投资者与普通投资者的互相转化
符合上述规定的法人,其他组织,或者自然人,可以书面告知经营机构起选择其成为普通投资者,经营机构应当对其履行相应的适当性义务.符合下列条件之一的普通投资者可以申请成为专业投资者,但是经营机构有权自主决定是否同意转化.
证券经营机构对其告知警示资料及录音录像资料的保存期限不得少于20年.
## 法人或者其他组织
最近1年末净资产不低于1000万元，最近1年末金融资产不低于500万元，且具有1年以上证券、基金、期货、黄金、外汇等投资经历
## 自然人
金融资产不低于300万元或者最近3年个人年均收入不低于**30万元**(==五转三==)，且具有1年(==折半==)以上证券、基金、期货、黄金、外汇等投资经历或者1年以上金融产品设计、投资、风险管理及相关工作经历

# 与 [[合格投资者]]的区别
| 区别点        | 合格投资者                  | 专业投资者                |                 |
| ---------- | ---------------------- | -------------------- | --------------- |
| **侧重点**    | "有钱"——财务实力             | "懂行"——专业能力           |                 |
| **个人资产门槛** | 300万/500万/年收入40万       | 500万金融资产             |                 |
| **知识经验要求** | 仅需2年投资经历               | 强调专业背景、职业资格、工作经历     |                 |
| **适用场景**   | 资管产品（银行理财、信托、[[非公开募集基金 | 私募基金]]等）的认购门槛        | 投资者适当性匹配、风险等级划分 |
| **转化关系**   | 专业投资者可申请转化为普通投资者       | 普通投资者满足条件可申请转化为专业投资者 |                 |
