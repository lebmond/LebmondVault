
# 定义
基金通过==公开募集或非公开募集==的方式,汇集投资者的资金形成独立财产,由专业的基金管理机构按照约定的投资目标,投资范围和投资策略进行投资管理,投资者按照所持有的基金份额享有投资收益并承担投资风险.

# 分类
## 通过募集渠道分类
###  公开募集基金
是指向不特定对象募集资金或者向特定对象募集资金==累计超过200人==设立的基金;
我国目前的公募基金只有公募证券投资基金.
### [[非公开募集基金]]

##  通过投资标的物分类
### 证券投资基金
主要投资于传统金融资产,即公开市场交易的股票,债券,[[货币市场工具]],证券投资基金份额,期货等金融资产.
#### 公开募集
1. [[债券基金]]:80%
2. 股票基金:80%
3. FoF基金:80%
4. [[货币市场基金]]:仅投资于[[货币市场工具]]
#### 非公开募集
(1)固定收益类: 投资于存款,债券等债权类资产的比例不低于私募证券投资基金已投资产80%的基金,已投资产不包含现金管理工具.
(2)期货和衍生品类: 投资于期货和衍生品的持仓合约价值的比例不低于私募证券投资基金已投资产80%,且期货和行生品账户权益超过私募证券投资基金已投 资产20%的基金.
(3)权益类:投资于股票等股权类资产的比例不低于私募证券投资基金已投资产80%的基金.
(4)混合类.

### 股权投资基金
仅限于**私募基金**: 
1. 私募股权投资基金:指对==非上市企业==进行权益性投资的基金.
2. 创业投资基金:投向处于==初创期的或者是小型==的新型企业,尤其是高新技术企业.

## 根据法律形分类
### 契约型基金
是指未成立法律实体,而是通过==契约形式==设立的基金,其法理本质是==信托==架构.
按照契约合同行驶权利和承担责任
### 合伙型基金
(较为普遍) 
是指投资者依据<合伙企业法>成立有限合伙企业作为基金;
合伙型基金本身**不是一个法人主体**,由普通合伙人和有限合伙人组成,有限合伙人以其认缴的出资额为限对合伙企业债务承担责任,普通合伙人对合伙企业的债务承担**无限连带责任**;
[[基金管理人]]具体负责投资运作(普通合伙人可以自任[[基金管理人]],也可以另行委托专业机构作为受托人具体负责投资运作)
### 公司型基金
(中国境内较少)是指投资者依据<公司法>,通过出资形成独立的公司法人**实体**,即基金公司,由基金公司自行或者通过委托专门的[[基金管理人]]进行管理的基金;
公司型基金的投资者**既是基金份额持有人,又是该基金公司的股东**,按照公司章程行使相应权利,承担相应义务和责任.

## 通过运作方式来分类
### 开放式基金
指采用开放方式运作的基金,其基金份额总额不固定.==可能会有一个封闭期(不超过三个月)==
### 封闭式基金
指采用封闭方式运作的基金,其基金份额总额在基金合同期限内固定不变.

## 通过管理策略来分类
### 主动型基金
采用主动投资策略
### 被动型基金
采用被动投资管理策略,力图通过控制跟踪误差复制标的指数的表现.

# 对比不同类型的基金
## 基金的共同特点
### 1. 财产的汇集性
金财产主要通过公开或非公开的方式向投资者募集形成,并委托基金管理人按照合同约定的投资**目标,投资范围和投资策略**对其进行投资管理.
### 2. 财产的独立性 （基金最典型的特征）
(==最典型的特征==
#### 账户独立:
基金财产开立独立银行账户等各类运作账户,确保基金财产的安全性和独立性.
#### 财产独立: 
基金财产独立于基金份额持有人,基金管理人与基金托管人,
#### 运作独立:
基金财产的管理运作**严格区分**.基金管理人与托管人因基金财产的管理,运用或者其他情形而取得的财产和收益,归入基金财产;基金财产的债权,不得与基金管理人与托管人固有财产的债务相抵销;不同基金财产的债权债务,不得相互抵销;非因基金财产本身承担的债务,不得对基金财产强制执行.
#### 责任有限
基金财产的债务由基金财产本身承担,基金份额持有人以其投资为限对基金财产的债务承担责任,但基金合同另有约定的从其约定.
### 3. 财产使用和基金运作的特定目的性
基金的专有目的是投资管理,资产管理.
### 4. 管理的专业性
基金的运作需要专门的机构进行管理.
1. 公司型基金需要设立董事会来管理.
2. 合伙型基金需要普通合伙人(或执行事务合伙人)或由其聘请基金管理人来管理.
3. 契约型基金一般由基金管理人直接管理.
4. 私募资产管理计划一般由证券公司,期货公司与公募基金管理公司管理.

## 基金与股票、债券的差异
1. 性质不同
	- 基金：反映的是一种信托关系。
	- 股票：反映的是一种股东权利关系，是一种股东权利凭证;
	- 债券：反映的是债权债务关系，是一种债权凭证。
2. 投向不同
	- 基金：间接投资工具，投向有价证券、未上市股权等；
	- 股票、债券：直接投资工具，投向实业领域。
## 与银行存款的差异
1. 性质不同：
	- 基金：是一种资管产品和投资理财工具，其作为独立财产独立承担风险；基金管理人只是受托管理基金财产，一般情况下并不承担基金投资损失的风险。基金风险自负。
	- 银行储蓄存款：表现为银行的负债，银行对存款人负有法定的还本付息义务。存款**保本保息**。
2. 收益与风险不同：
	- 基金：收益具有一定的波动性，存在投资损失的风险。
	- 银行储蓄存款：利率相对固定，投资者损失本金的可能性也很小。
3. 信息披露程度不同：
	- 基金：基金管理人必须在法定时间依法向投资者公布基金的投资运作情况并披露各类临时信息。
	- 银行储蓄存款：银行吸收存款后，不需要向存款人披露资金的使用情况。
4. 发行主体不同
	1. 基金：基金管理人。
	2. 银行理财产品：商业银行或银行理财公司。
5. 销售渠道不同
	- 基金：基金管理人直销或者银行、证券公司及独立基金销售机构等具有基金销售牌照的机构代销。
	- 银行理财产品：银行渠道。
6. 投资管理方式不同
	- 基金：主要由发行人自行投资管理。
	- 银行理财产品：既可以由发行主体自行进行投资管理，也可以由理财投资合作机构共同投资管理。
7. 监管主体不同
	- 基金：==[[中国证监会]]==。
	- 银行理财产品：金融监管总局。
## 基金与期货、期权的差异

|          | 基金                  | 期货、期权            |
| -------- | ------------------- | ---------------- |
| 性质不同     | 对应具体财产              | 约定买卖标的物权利义务的合同   |
| 交易方向不同   | 单向交易                | 双向交易             |
| 交易期限不同   | 基金合同约定的期限内认（申）购并持有  | 需在合约到期前进行交割或行权   |
| 风险收益特征不同 | 一般不常用保证金交易方式，风险相对较小 | 采用保证金交易方式，风险相对较大 |
## 基金与保险产品的差异
1. 目的不同
	- 基金：获得投资收益。
	- 保险产品：主要功能是保障，目的是分散或者转移风险。
2. 对投资人要求不同
	- 基金：没有太多个性化要求，统一的申购和赎回价格计算方式。
	- 保险产品：保险产品的购买是个性化的，价格的计算方法不同。

## 基金作用
### 公募基金作用
1. 是广大投资者拓宽投资渠道、丰富资产配置的重要==工==具。有专业管理、组合投资、分散风险等特点，可以较好地匹配投资者的风险收益特征；
2. 是资本市场稳定发展的**压舱==石**==;
3. 是金融服务于实体经济的==推==进器；
4. 是资本市场对外开放和全球化、国际化的==先==行者。
### 私募基金的作用
#### 私募证券投资基金的作用
1. 是多层次资本市场的建设者;
2. 是市场价格发现的参与者和市场流动性的提供者;
3. 是实体经济转型深化的助力者;
4. 是跨境和国际化投资的开拓者。
#### 私募股权投资基金的作用
1. 促进经济创新发展；
2. 为中小微企业提供资金支持（通过参股、提供长期权益资本等方式）；
3. 有效形成长期权益资本（实现储蓄向投资的转化）；
