1. 基金进行跨境投资、销售或管理等被称为基金国际化。基金的国际化是伴随着经济全球化、证券市场国际化的发展出现的，是当前基金行业发展的重要趋势之一。
2. 我国公募基金管理人开展基金国际化业务历程
	1. 申请[[合格境内机构投资者基金|QDII]]资格和额度开展境外投资；
	2. 设立境外经营机构拓展境外业务；
	3. 通过基金互认在境外市场向公众投资者销售基金；
	4. 通过互联互通机制交易香港市场的股票等多元化发展的国际业务。

# 一、合格境内机构投资者境外证券投资
**境内基金管理公司和证券公司**(不包括银行和保险公司)等证券经营机构在取得[[合格境内机构投资者基金|QDII]]资格后，可以向国家外汇管理局申请境外证券投资额度，获批后可在批准额度内按照规定开展境外证券等投资。

# 二、公募基金管理人境外经营机构
《证券公司和证券投资基金管理公司境外设立收购、参股经营机构管理办法》主要包括四个方面的内容：
1. 维持适当门槛，支持机构“走出去”
2. 规范业务范围，完善组织架构。
3. 督促母公司加强管控，完善境外
4. 机构管理。加强持续监管，完善跨境监管合作。

# 三、基金互认
是指允许境外注册并受当地监管机构监管的基金向本地居民公开销售。中国证监会、香港证监会已经通过基金互认。

# 四、内地与香港股票市场交易互联互通机制
1. 内地与香港股票市场交易互联互通机制，是指上交所、深交所分别和香港联合交易所建立技术连接，使内地和香港投资者可以通过当地证券公司或经纪商买卖规定范围内的对方交易所上市的股票。
2. 目前，内地与香港股票市场交易互联互通机制包括沪港通和深港通。
互联互通： 沪港通、深港通。 债券通： 北向通、南向通
