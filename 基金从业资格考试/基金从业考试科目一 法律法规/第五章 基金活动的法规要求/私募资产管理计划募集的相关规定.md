# 一、募集主体
资产管理计划的募集主体为**证券期货经营机构**及具有公募基金销售资格的销售机构。证券期货经营机构可以自行销售和推介资产管理计划，也可以委托具有公募基金销售资格的销售机构销售和推介资产管理计划。

# 二、募集对象
资产管理计划应当向[[合格投资者]]募集。
### 计划分类
A 资产管理计划包括为单一投资者设立的**单一资产管理计划**，以及面向多个投资者设立的**集合资产管理计划**。
B 集合资产管理计划的投资者人数不少于2人，不超过200人，符合条件的员工持股计划不穿透计算员工人数。

# 三、募集方式
应当以非公开的形式募集

# 四、募集金额要求
风险越低,这里的金额下限越低,但是最高不会高于100万.
1. [[合格投资者]]投资于单只固定收益类资产管理计划的金额不低于30万元，投资于单只混合类资产管理计划的金额不低于40万元，投资于单只权益类、期货和衍生品类资产管理计划的金额不低于100万元。
2. 资产管理计划投资于规定的非标准化资产，单个合格投资者参与资金的金额**不得低于100万元**；以及根据资产管理计划合同的约定，投资股权类、期货和行生品类资产比例可以达到80%的混合类资产管理计划，接受单个合格投资者参与资金的金额**不得低于100万元**。
3. 资产管理计划的初始募集规模**不得低于1000万元**。
4. 封闭式资产管理计划的投资者可以分期缴付参与资金。
5. 单个投资者首期缴付金额不得低于合格投资者参与单个资产管理计划的最低投资金额，所有投资者**首期缴付**金额合计不得少于**1000万元**。

# 五、募集期限要求
集合资产管理计划的初始募集期自资产管理计划份额发售之日起**不得超过60天**，专门投资于未上市企业股权的集合资产管理计划的初始募集期自资产管理计划份额发售之日起不得超过12个月。
- 集合资产管理计划的募集金额缴足之日起==10个工作日内==，由证券期货经营机构公告资产管理计划成立；
- 单一资产管理计划在受托资产入账后，由证券期货经营机构书面通知投资者资产管理计划成立。

# 六、募集资金出资形式
## 单一资产管理计划
可以接受货币资金出资，或者接受投资者合法持有的股票、债券或中国证监会认可的其他金融资产出资。
## 集合资产管理计划
原则上应当接受货币资金出资，中国证监会认可的情形除外。

### 七、募集失败
- 证券期货经营机构以其固有财产承担因募集行为而产生的债务和费用；
- 在募集期**届满后30日内**返还投资者已缴纳的款项，并加计银行同期活期存款**利息**。
