达到一定资产规模并且具备**相应风险识别能力和风险承受能力**，投资于单只私募资产管理计划或者私募基金不低于一定金额且符合下列条件的自然人、法人或者其他组织。
# 自然人
具有2年以上投资经历，且满足下列三项条件之一的自然人：
1. 家庭金融净资产不低于300万元
2. 家庭金融资产不低于500万元
3. 或近3年本人年均收入不低于40万元(区别于[[专业投资者]]50万;此外,对自然人投资私募基金时的年收入也不得低于50万).
# 法人
1. 最近1年末净资产不低于1000万元的法人单位
2. 依法设立并接受国务院金融监督管理机构监管的机构，中国证监会认定的其他机构
3. 接受国务院金融监督管理机构监管的机构发行的资产管理产品
4. 基本养老金、社保基金、年金基金等养老基金，慈善基金等社会公益基金，合格境外机构投资者、人民币合格境外机构投资者

# 与[[专业投资者]]的区别
| 区别点        | 合格投资者                    | 专业投资者                |
| ---------- | ------------------------ | -------------------- |
| **侧重点**    | 识别能力+承受能力                | "懂行"——专业能力           |
| **个人资产门槛** | 300万/500万/年收入40万         | 500万金融资产             |
| **知识经验要求** | 仅需2年投资经历                 | 强调专业背景、职业资格、工作经历     |
| **适用场景**   | 资管产品（银行理财、信托、私募基金等）的认购门槛 | 投资者适当性匹配、风险等级划分      |
| **转化关系**   | 专业投资者可申请转化为普通投资者         | 普通投资者满足条件可申请转化为专业投资者 |
