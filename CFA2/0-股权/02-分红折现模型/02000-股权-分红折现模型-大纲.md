# Discounted Dividend Model
If assuming the dividend goes infinity and a termination value is not provided:
$$
V_{0}=\sum_{i=1}^\infty \frac{D_{i}}{(1+r_{i})^i}
$$
If assuming a termination value in $t$ years later:
$$
V_{0}=\sum_{i=1}^t\frac{D_{i}}{(1+r_{i})^t}+\frac{P_{t}}{(1+r_{t})^t}
$$
