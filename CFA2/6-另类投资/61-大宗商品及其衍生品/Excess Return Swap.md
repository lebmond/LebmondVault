---
aliases:
  - 超额回报互换
---
The long side of the excess return swap longs the excess returns of a certain commodity futures contracts. 

本质上来说,超额回报互换的多方是在做多一系列的大宗商品看涨期权,想要赚取"风险溢价/相对回报 / 超额回报".
类似于[[Total Return Swap|总回报互换]],多方和空方通常来说都是对冲基金([[Hedge Fund]]s,尤其是使用CTA策略的)和资产管理机构.但前者也会包括相当多的保险公司和养老金,这点上不多见与[[Excess Return Swap|超额回报互换]].

## Contrast [[Total Return Swap]], [[Excess Return Swap]] & [[Basis Swap]]

| **产品**                     | **投资者关注点**                             | **投资者类型特征**                                                  | 多方获得            | 多方目的        |
| -------------------------- | -------------------------------------- | ------------------------------------------------------------ | --------------- | ----------- |
| **[[Total Return Swap]]**  | 获取完整经济敞口：价格变动 + 分红/票息 + 资产持有收益         | 想获得资产敞口但不想直接持仓<br>（如对冲基金、资产管理机构、保险公司和养老金）                    | 总回报（价格 + 分红/票息） | 获得完整敞口      |
| **[[Excess Return Swap]]** | 获取相对表现：资产价格回报减去融资成本（纯超额回报）             | 追求风险溢价相对价值策略<br>（如对冲基金、资产管理机构）                               | 超额回报（价格 – 融资）   | 获得风险溢价/因子敞口 |
| **[[Basis Swap]]**         | 锁定两种价格之间的价差（如 Brent–WTI、不同交割月份、不同地点差价） | 多为实物商品使用者（炼油厂、航空公司、化工企业）与做市行，用于对冲基差风险；<br>同时也被一些金融机构用于基差交易策略 | 两个价格的差值变化       | 对冲基差风险      |
